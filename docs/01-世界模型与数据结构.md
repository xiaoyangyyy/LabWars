## 1. 世界设定

### 1.1 时间与轮次

| 参数 | 值 |
|------|-----|
| 1 轮 | 3 天 |
| 总轮数 | 60 轮 |
| 总时长 | 180 天（6 个月） |
| 目标会议 | NeurIPS / ICML / ICLR 风格顶会 |

### 1.2 每轮发生顺序

```
1. 事件生成（mandatory anchor 或 state-triggered）
2. 各 Agent 记忆召回
3. 各 Agent 行为生成（action-field sampled primary + LLM public/private stance + memory write）
4. 状态更新（emotion / belief / relationship / project）
5. 贡献 ledger 更新
6. 信任图更新
7. 轮次日志写入
```

## 4. 关系图 Schema

每条边：

```json
{
  "source": "phd_a",
  "target": "phd_b",
  "trust": 0.42,
  "resentment": 0.36,
  "dependency": 0.61,
  "obligation": 0.21,
  "perceived_credit_threat": 0.78,
  "communication_frequency": 0.55,
  "alliance": 0.0,
  "information_access": 0.50,
  "last_interaction_valence": -0.4
}
```

### 4.1 五类核心图

| 图 | 主边字段 | 用途 |
|----|----------|------|
| trust graph | `trust` | 合作意愿 |
| credit-threat graph | `perceived_credit_threat` | 抢功感知 |
| dependency graph | `dependency` | 资源/毕业依赖 |
| alliance graph | `alliance` | 私下结盟 |
| resentment graph | `resentment` | 长期怨恨 |

`information_access` 独立维护，表示谁知道什么。

## 6. 动作空间

每 Agent 每轮最多：

| 类型 | 数量 | 说明 |
|------|------|------|
| primary action | 1 | 由 continuous latent action field 采样；研究/政治/信息/情绪/外部 |
| communication action | 1 | 对特定 target 的发声 |
| memory write | 1 | 结构化记忆写入 |

### 6.1 动作枚举

**研究动作**

| action | 影响 project 字段 |
|--------|-------------------|
| `run_experiment` | experimental_strength ↑ |
| `improve_baseline` | baseline_coverage ↑ |
| `write_section` | writing_quality ↑ |
| `debug_code` | code_stability ↑ |
| `analyze_failure` | novelty_risk ↓ or ↑ |
| `prepare_rebuttal` | writing_quality ↑ |
| `open_source_code` | code_stability ↑, trust ↑ |
| `withhold_code` | code_stability ↓, credit_threat ↑ |

**政治动作**

| action | 典型效果 |
|--------|----------|
| `ask_for_authorship` | authorship_conflict ↑ |
| `privately_lobby_pi` | pi_access 相关 |
| `support_teammate` | trust ↑, alliance ↑ |
| `undermine_teammate` | trust ↓, resentment ↑ |
| `form_alliance` | alliance ↑ |
| `leak_concern` | information_access 变化 |
| `request_mediation` | conflict 可能 ↓ |
| `delay_response` | deadline_pressure ↑ |

**信息动作**

| action | 典型效果 |
|--------|----------|
| `share_result` | team_trust ↑ |
| `hide_negative_result` | integrity_risk ↑ |
| `selectively_report` | public_private_divergence ↑ |
| `challenge_claim` | authorship_conflict ↑ |
| `document_contribution` | ledger 更新 |
| `cite_prior_memory` | memory rehearsal ↑ |

**情绪动作**

`confront` | `withdraw` | `apologize` | `blame` | `seek_validation` | `comply` | `rebel`

**外部动作**

`contact_collaborator` | `check_rival_arxiv` | `submit_workshop_version` | `talk_to_alumni` | `notify_program_officer`
