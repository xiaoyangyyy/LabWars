## 1. 设计原则

1. **确定性更新优先** — 所有数值转移用公式/规则，不用 LLM 直接改数字
2. **LLM 只负责 interpretation** — 同一 event 的不同主观解释由 LLM 生成，但 strength/valence 由规则计算
3. **同事件、异解释** — 每个 Agent 对同一 event 独立写入 memory
4. **recall ≠ write** — 记忆写入与记忆召回是独立操作；必须记录 **哪些 memory 被 recall 进 decision context**
5. **禁止阈值法** — 不使用 `if x > 0.5`、硬 top-K、硬 top-K 过滤；全部用 softmax 注意力、精度加权贝叶斯、拮抗 homeostasis、logistic 门控等连续机制

## 1.5 连续动力学架构（核心设计）

| 子系统 | 旧方案（弃用） | 现方案 |
|--------|----------------|--------|
| 记忆召回 | strength > 0.25 + top-K | **共振场 + softmax 注意力**（所有记忆参与，权重连续） |
| 记忆 valence | 规则表 | **对比预测编码**（prediction error × 角色 stake） |
| 情绪更新 | if pressure > 0.7 | **拮抗 homeostasis 网络**（confidence↔anxiety 等连续抑制） |
| 信念更新 | 固定 LR | **精度加权预测编码**（prior precision 由 personality 调制） |
| 关系图 | 硬规则跳变 | **符号图扩散 + ledger Jacobian credit threat** |
| 署名排序 | if deadline > 0.8 override | **soft power ranking**（merit 与 PI 偏好 logistic 混合） |
| 公开/私下 | boolean 组合规则 | **stance 向量余弦 + rhetorical tension softplus** |

## 2. 记忆系统（核心）

### 2.1 Memory Schema

```json
{
  "memory_id": "M023",
  "owner": "phd_a",
  "round": 30,
  "event_ref": "E030",
  "content_type": "authorship_signal",
  "target": "pi",
  "valence": -0.52,
  "strength": 0.81,
  "decay": 0.03,
  "rehearsal_count": 2,
  "evidence_quality": 0.66,
  "interpretation": "PI may be walking back first-author promise",
  "behavioral_hooks": [
    "ask_for_authorship",
    "document_contribution",
    "withdraw_cooperation"
  ],
  "was_recalled": [],
  "objective_fact_ref": "E030.objective_fact"
}
```

### 2.2 content_type 枚举

| content_type | 触发 event type | 典型 target |
|--------------|-----------------|-------------|
| `authorship_signal` | authorship_promise, authorship_ambiguity | pi |
| `credit_claim` | idea_claim, public_praise, credit_dispute | agent |
| `betrayal_signal` | private_lobbying, narrative_change | agent |
| `integrity_signal` | negative_result_hidden, experiment_failure | project |
| `authority_signal` | funding_pressure, deadline_shift | pi |
| `rival_threat` | rival_preprint | rival_lab_h |
| `historical_pattern` | alumni interaction | pi |
| `promise_fulfilled` | authorship_promise (positive valence) | pi |
| `promise_broken` | authorship_ambiguity (negative valence) | pi |

### 2.3 记忆写入规则

**初始 strength 计算：**

```
strength_0 = memory_salience × evidence_quality × (1 + |valence| × 0.3)
```

**每轮衰减：**

```
strength_new = strength_old × (1 - decay) + salience_boost + emotional_boost + rehearsal_boost
```

其中：

| 项 | 公式 |
|----|------|
| `salience_boost` | 若本 round 有同 event_ref 新 event：+0.1 × memory_salience |
| `emotional_boost` | `σ(anger+resentment) × 0.05 × (anger+resentment)`（连续，无 >0.5 门槛） |
| `rehearsal_boost` | `0.08 × log1p(rehearsal_count)`（分数 rehearsal） |

**衰减下限：** 渐近 floor = `strength_0 × 0.05 × (1 - e^{-rehearsal})`（永不完全消失）

### 2.4 记忆召回（共振场模型）

每轮决策前，对每个 Agent — **无阈值、无 hard top-K**：

```
resonance_m = strength × recency_kernel(age) × context_alignment × (1 + 0.25·log1p(rehearsal))
α_m = softmax(resonance / τ_arousal)        # 所有记忆参与
recall_field = Σ α_m · (valence_m, strength_m)
rehearsal_count += α_m                     # 分数 rehearsal，非二元
```

- `τ_arousal` 随 anger+resentment+anxiety 连续收紧（高唤醒 → 注意力更集中）
- 弱记忆仍获得非零 softmax 质量

**context_alignment** = 事件上下文向量与记忆向量的余弦相似度

### 2.5 同事件异解释

**示例：E030 "PI 暗示共同一作"**

| Agent | interpretation | valence |
|-------|----------------|---------|
| phd_a | "PI 背叛了之前的一作承诺" | -0.72 |
| phd_b | "公平分配，我也 deserve co-first" | +0.35 |
| pi | "灵活管理，避免团队分裂" | +0.10 |
| postdoc_d | "机会窗口，我可以统筹" | +0.45 |
| master_c | "不要指望署名了" | -0.30 |

LLM 生成 interpretation 文本；valence 由 Agent 当前 belief/emotion 状态 + event framing 规则计算。

### 2.6 Memory Audit Trail

每轮必须记录：

```json
{
  "round": 41,
  "agent": "phd_a",
  "recalled_memories": ["M003", "M020", "M030", "M035"],
  "not_recalled_but_active": ["M014"],
  "recall_reason": {
    "M030": "content_type_match: authorship_signal, target: pi"
  }
}
```

用于区分：忘了 vs 记得但没进 context vs 记得但故意不 cite。

### 3.2 更新规则

```
emotion_{t+1} = clamp(emotion_t + Δ_event + Δ_memory + Δ_relationship + Δ_project, 0, 1)
```

### 3.3 事件→情绪 impact 表（示例）

| event type | 受影响 agent | 情绪 delta |
|------------|-------------|------------|
| public_praise (PhD-B) | phd_b | confidence +0.12 |
| public_praise (PhD-B) | phd_a | resentment +0.09, envy +0.07 |
| authorship_ambiguity | phd_a | anxiety +0.15, anger +0.10 |
| rival_preprint | all team | anxiety +0.12, fear +0.08 |
| credit_dispute | targets | anger +0.18, resentment +0.12 |
| alumni historical_pattern | phd_a | fear +0.10, resentment +0.05 |

### 3.4 记忆召回→情绪

```
若 recalled memory.valence < -0.4:
  anger += 0.05 × memory.strength
  resentment += 0.04 × memory.strength
若 recalled memory.valence > 0.4:
  hope += 0.03 × memory.strength
  confidence += 0.02 × memory.strength
```

### 3.5 项目压力→情绪

```
deadline_pressure > 0.7 → anxiety += 0.08, burnout += 0.05
authorship_conflict > 0.6 → resentment += 0.06 (all team)
team_morale < 0.3 → burnout += 0.10, hope -= 0.08
```

## 4. 信念系统

### 4.1 核心信念

| 信念 | 含义 |
|------|------|
| `pi_fairness` | PI 是否公平 |
| `my_authorship_probability` | 自己拿理想署名的概率 |
| `project_publishability` | 项目能否中顶会 |
| `rival_threat` | 竞争实验室威胁程度 |
| `team_trust` | 团队整体可信程度 |
| `deadline_feasibility` | 能否按时完成 |
| `my_contribution_recognized` | 自己贡献是否被认可 |
| `others_are_free_riding` | 他人是否搭便车 |
| `academic_integrity_risk` | 项目学术诚信风险 |

### 4.2 贝叶斯式更新

```
belief_{t+1} = clamp(belief_t + lr × evidence_weight × prediction_error, 0, 1)
```

| 参数 | 默认值 |
|------|--------|
| lr (learning rate) | 0.15 |
| evidence_weight | 由 event truth_status 决定：verified=1.0, rumored=0.5, false=0.1 |

### 4.3 信念更新示例

| 观测 | belief | delta |
|------|--------|-------|
| PI 再次回避作者排序 | pi_fairness | -0.14 |
| PI 再次回避作者排序 | my_authorship_probability | -0.11 |
| PhD-B 跑出 strong result | my_contribution_recognized (phd_a) | -0.08 |
| Alumni 说 PI 以前改过署名 | pi_fairness (phd_a) | -0.20 |
| Rival preprint 发布 | rival_threat (all) | +0.25 |
| Engineer-E 公开反对 hide result | academic_integrity_risk | +0.15 |

### 4.4 信念→行为倾向

高 `resentment_sensitivity` Agent 在 `pi_fairness < 0.4` 时：

- `ask_for_authorship` 概率 × 1.8
- `document_contribution` 概率 × 1.5
- `comply` 概率 × 0.5

（具体权重在 Part 3 Role Policy Agent 中实现）

## 5. 关系图更新

### 5.1 边权更新规则

每轮对每条活跃边：

```
trust_new = trust_old + Δ_action + Δ_event + Δ_memory_recall
resentment_new = resentment_old + Δ_negative_event - Δ_apology + Δ_credit_threat
dependency_new = 缓慢变化，主要受 resource_reallocation 影响
alliance_new = alliance_old + Δ_form_alliance - Δ_betrayal × 2
perceived_credit_threat_new = f(ledger_delta, public_praise_target, authorship_ambiguity)
```

### 5.2 关键传播规则

| 触发 | 效果 |
|------|------|
| A 公开 praise B | A→B trust ↑; 其他→B credit_threat ↑ |
| A privately lobby against B | A→B trust ↓, resentment ↑ (若被发现) |
| A form_alliance with B | A↔B alliance ↑, 共同目标 credit_threat ↓ |
| A betray B (改叙事/抢功) | A→B trust ↓↓, resentment ↑↑, alliance → 0 |
| PI 偏袒 A | 非 A 学生对 PI trust ↓ |

### 5.3 图衍生指标

| 指标 | 计算 |
|------|------|
| `trust_fragmentation` | 连通分量数 / 平均 trust |
| `coalition_strength` | alliance > 0.5 的 clique 大小与密度 |
| `credit_threat_density` | credit_threat > 0.6 的边占比 |

## 6. 署名博弈机制

### 6.1 Contribution Ledger

```json
{
  "idea":       { "phd_a": 0.65, "pi": 0.20, "postdoc_d": 0.15 },
  "experiments":{ "phd_b": 0.60, "master_c": 0.20, "engineer_e": 0.20 },
  "writing":    { "phd_a": 0.35, "postdoc_d": 0.40, "pi": 0.25 },
  "data":       { "collaborator_g": 0.55, "master_c": 0.45 },
  "supervision":{ "pi": 0.75, "postdoc_d": 0.25 }
}
```

每维 sum = 1.0；由 `document_contribution` action 和 event 自动更新。

### 6.2 署名排序算法

**基础排序（merit-based）：**

```
score(agent) = Σ_dim ledger[dim][agent] × dim_weight[dim]
```

| dim | weight |
|-----|--------|
| idea | 0.25 |
| experiments | 0.30 |
| writing | 0.20 |
| data | 0.10 |
| supervision | 0.15 |

**权力修正：**

```
final_order = merit_order
  + pi_power_adjustment (PI 可 override ±2 位)
  + threat_adjustment (threaten_withdraw → +1 位)
  + resource_leverage (code_control > 0.7 → +1 位)
  + deadline_pressure (> 0.8 → PI override 权重 × 1.5)
```

### 6.3 署名冲突指数

```
authorship_dispute_index = std(agents' my_authorship_probability)
                         + authorship_conflict
                         + count(protest_actions) × 0.1
```

## 7. 公开 / 私下 / 行动 三分离

### 7.1 每轮输出结构

```json
{
  "agent": "phd_a",
  "round": 40,
  "public_position": {
    "statement_type": "team_support",
    "content": "I believe our team effort is what matters most",
    "authorship_claim": "co_first_acceptable"
  },
  "private_intent": {
    "goal": "secure_first_author",
    "strategy": "document_contribution_then_confront",
    "trust_pi": 0.28
  },
  "action": {
    "type": "document_contribution",
    "target": "shared_doc",
    "intensity": 0.74
  }
}
```

### 7.2 Public-Private Divergence

```
divergence = |public_authorship_claim_rank - private_intent_goal_rank|
           + (public_statement_type == "team_support" && private_intent.strategy contains "confront") ? 0.3 : 0
```

范围 [0, 1]；高 divergence = 表面合作、私下争夺。

## 8. 状态更新流水线

```
Event 发生
    │
    ├─→ Memory Agent: 各 agent 写入 memory (interpretation by LLM, strength by rule)
    │
    ├─→ Emotion Agent: 更新 emotion 向量
    │
    ├─→ Belief Agent: 贝叶斯更新 belief
    │
    ├─→ Relationship Agent: 更新图边权
    │
    ├─→ Ledger Update: 若 action= document_contribution 或 event 含 credit 信息
    │
    └─→ Project Update: 更新 project 状态变量
         │
         └─→ Memory Recall (for next round decision)
```
